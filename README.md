# Ereyx

Учебный проект.

## Структура

- `index.html`, `app.js`, `styles.css` — основной интерфейс Mini Figma (чистый HTML/CSS/JS)
- `mini-figma/` — версия на React + TypeScript + Vite
- `about-me/` — страница знакомства

## Запуск

### Версия на чистом HTML/CSS/JS

Откройте `index.html` в браузере.

### Версия mini-figma (React + Vite)

```powershell
cd mini-figma
npm install
npm run dev
```
